# Auditoría pendiente: comprobaciones en ejecución

Este archivo lista lo que no se puede determinar leyendo los archivos del orquestador y debe comprobarse ejecutando Claude Code en una sesión nueva. Cada fila corresponde a un `[VERIFICAR]` de otros documentos. Las rutas son absolutas desde `~/.claude/`.

Estado: parcial. Desde 0011 ([ADR](decisions/0011-doctor-y-e2e.md)) varias filas se comprueban con el E2E de `tests/e2e/` (`make e2e`, opcional y fuera de CI): Claude Code real contra un servidor local que imita la API de Messages, sin API key ni coste. Resultados con Claude Code 2.1.312; al actualizar Claude Code, vuelve a ejecutar `make e2e`. La instalación en sí se comprueba con `/orch-doctor`.
